## 1. 概述

**对比学习**是一种自监督学习方法，其核心思想是：将**相似样本拉近**、**不相似样本推远**，从而学习出有判别性的表示（representation）。

它在 **计算机视觉**、**自然语言处理** 和 **图神经网络** 等领域取得了显著成功，尤其在预训练阶段用于获取通用表征。

## 2. 核心原理

对比学习的目标是构造一种特征空间，使得：

- 同一个样本的不同增强视图（**正样本对**$z1$,$z2$...）在该空间中尽可能接近；
- 来自不同样本的数据对（**负样本对**）尽可能远离。

然后用某种**对比损失函数**来拉近 $z1$ 和 $z2$，推远 $z1$ 与其他样本的表示。

## 3. 常见实现方法

### 3.1 数据增强策略

对比学习的性能强烈依赖于输入的**数据增强**方式，常见方法包括：
- 图像：随机裁剪、颜色抖动、高斯模糊等。
- 文本：同义词替换、句子重排序、词删除等。
- 图结构：边扰动、节点特征遮蔽等。

### 3.2 Encoder结构

- 图像：通常使用 ResNet、ViT
- 文本：BERT、RoBERTa、Transformer
- 图数据：GNN（Graph Neural Networks）

## 4. 损失函数

### 4.1 NT-Xent Loss（Normalized Temperature-scaled Cross Entropy Loss）

（如 SimCLR）
$$L_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \ne i]} \exp(\text{sim}(z_i, z_k)/\tau)}$$

- $\text{sim}(z_i, z_j)$：$z$ 的余弦相似度
- $\tau$：温度系数（温度越低，越强调区分度）
- 计算效率高，可批量训练

### 4.2 InfoNCE Loss

（如 MoCo）
类似于 NT-Xent，但一般使用一个队列（memory bank）来存储负样本表示。

### 4.3 Triplet Loss

$$\mathcal{L} = \max(0, d(a, p) - d(a, n) + \alpha)$$
- $a$：anchor，$p$：正样本，$n$：负样本
- 控制正样本更靠近 anchor，负样本远离 anchor

## 5. 经典方法

| 方法                  | 模型结构             | 关键机制              |
| ------------------- | ---------------- | ----------------- |
| SimCLR (2020)       | Siamese          | 大 batch + NT-Xent |
| MoCo (2020)         | Momentum encoder | 负样本动态队列           |
| BYOL (2020)         | 不用负样本            | EMA 目标网络          |
| SimSiam (2021)      | 无负样本             | 偏置 stop-gradient  |
| Barlow Twins (2021) | 相关矩阵去冗余          | 无需负样本             |
| VICReg (2022)       | 方差+协方差正则         | 避免崩塌              |

## 6. 优点与挑战

## 优点

- **学习通用表征** 
	- 能学到迁移能力强的表示，在多个下游任务中（分类、检索、聚类）都表现优异。
- **适用于多模态数据**
	- 可用于图像、文本、音频、图结构等多种模态，甚至跨模态（如 CLIP）。
- **可与预训练-微调框架结合**
	- 作为预训练阶段的方法，之后可以结合微调实现更优性能。
- **模型架构通用性强** 
	- 大多数编码器结构（ResNet、Transformer、GNN）都能集成对比学习思想。
- **不需要明确任务目标** 
	- 与有监督学习相比，不需要事先定义任务标签或类别。

## 缺点

- **训练不稳定 / 容易崩塌**
	- 若没有负样本（或正负样本选择不当），模型容易学出无差异的无效表征（collapse）。
- **对数据增强高度依赖**
	- 表现效果对数据增强策略敏感，尤其在图像领域，不合适的增强方式会破坏语义。
- **难以构造负样本**
	- 负样本的选择对性能影响大，错误的负样本可能包含正样本（false negatives），导致学习受损。
- **需要较大的 batch size 或 memory bank**
	- 方法如 SimCLR 需大 batch 才能包含足够多的负样本，对显存要求高。
- **构建难以解释的表示空间**
	- 表征空间中距离的语义含义有时难以解释，特别是在高维空间中。

## 7. 应用场景

- 图像分类/检索
- 文本语义相似度
- 图结构表示学习（如 GraphCL）
- 多模态对齐（如 CLIP）
- 推荐系统中的用户/物品表征学习

## 8. 总结

对比学习通过拉近正样本对、推远负样本对，能够在无监督环境下学习高质量的特征表示，是现代深度学习中一种强大的自监督学习方法。尤其是在数据标注困难的场景下，它是一种值得优先考虑的预训练策略。
