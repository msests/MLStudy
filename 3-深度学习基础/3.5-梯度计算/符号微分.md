## 基本概念

**符号微分**（Symbolic Differentiation）通过对数学表达式进行解析变换来计算导数，与以下方法形成对比：
- 数值微分：通过有限差分近似
- 自动微分：基于计算图的中间值传播

梯度计算目标：对函数$f: \mathbb{R}^n \rightarrow \mathbb{R}$，求梯度向量
$$
\nabla f = \left[ \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \cdots, \frac{\partial f}{\partial x_n} \right]^T
$$

## 实现步骤

### 表达式分解

将函数分解为基本运算组成的表达式树，例如：
$$
f(x,y) = \sin(x^2) + e^{3y}
$$
对应的运算顺序：
1. $a = x^2$
2. $b = \sin(a)$
3. $c = 3y$
4. $d = e^c$ 
5. $f = b + d$

### 逐项求导

使用求导法则逐层计算偏导数：

| 表达式           | 导数规则                                           | 计算结果                                |
| ------------- | ---------------------------------------------- | ----------------------------------- |
| $a = x^2$     | $\frac{\partial a}{\partial x} = 2x$           | $\frac{\partial a}{\partial y} = 0$ |
| $b = \sin(a)$ | 链式法则 $\frac{\partial b}{\partial a} = \cos(a)$ | 复合求导                                |
| $c = 3y$      | $\frac{\partial c}{\partial y} = 3$            | $\frac{\partial c}{\partial x} = 0$ |
| $d = e^c$     | 链式法则 $\frac{\partial d}{\partial c} = e^c$     | 复合求导                                |
| $f = b + d$   | 线性法则 $\frac{\partial f}{\partial b} = 1$       | $\frac{\partial f}{\partial d} = 1$ |
### 链式法则组合

通过反向累积计算最终梯度：
$$
\frac{\partial f}{\partial x} = \frac{\partial f}{\partial b} \cdot \frac{\partial b}{\partial a} \cdot \frac{\partial a}{\partial x} = 1 \cdot \cos(x^2) \cdot 2x = 2x\cos(x^2)
$$
$$
\frac{\partial f}{\partial y} = \frac{\partial f}{\partial d} \cdot \frac{\partial d}{\partial c} \cdot \frac{\partial c}{\partial y} = 1 \cdot e^{3y} \cdot 3 = 3e^{3y}
$$

## 优点和缺点

**优点**
- 得到精确解析表达式
- 可进行后续符号化简（如$\sin^2x + \cos^2x \rightarrow 1$）
- 方便分析函数特性

**缺点**
- 表达式膨胀问题（尤其高阶导数）
- 需要实现完整的代数运算规则
- 对控制流语句（if/while）处理困难

## 代码示例

```python
import sympy as sp

x, y = sp.symbols('x y')
f = sp.sin(x**2) + sp.exp(3*y)

# 计算梯度
grad = [sp.diff(f, var) for var in (x, y)]

print("梯度向量：")
print(f"∂f/∂x = {grad[0]}")
print(f"∂f/∂y = {grad[1]}")

输出结果：

梯度向量：
∂f/∂x = 2*x*cos(x**2)
∂f/∂y = 3*exp(3*y)
```
