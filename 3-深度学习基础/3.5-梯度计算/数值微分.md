## 概述

数值微分（Numerical Differentiation）是通过**有限差分法**近似计算导数的技术。当解析法难以直接求导时（例如黑盒函数），可通过函数值的差分来估计梯度。

对于函数 $f: \mathbb{R}^n \to \mathbb{R}$，梯度计算目标：
$$
\nabla f(\mathbf{x}) = \left(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n}\right)
$$

## 基本差分公式

### 前向差分 (Forward Difference)
$$
\frac{\partial f}{\partial x_i} \approx \frac{f(\mathbf{x} + h\mathbf{e}_i) - f(\mathbf{x})}{h}
$$
- $\mathbf{e}_i$ 表示第 $i$ 个标准基向量
- 截断误差：$O(h)$

### 中心差分 (Central Difference)
$$
\frac{\partial f}{\partial x_i} \approx \frac{f(\mathbf{x} + h\mathbf{e}_i) - f(\mathbf{x} - h\mathbf{e}_i)}{2h}
$$
- 截断误差：$O(h^2)$
- 精度更高但需要两次函数计算

## 实现步骤

```python
def numerical_gradient(f, x, h=1e-5):
    grad = np.zeros_like(x)
    for i in range(x.size):
        xi_original = x[i]
        
        # 前向差分计算
        x[i] = xi_original + h
        f_forward = f(x)
        
        # 中心差分计算
        # x[i] = xi_original - h
        # f_backward = f(x)
        # grad[i] = (f_forward - f_backward) / (2*h)
        
        x[i] = xi_original  # 恢复原始值
        grad[i] = (f_forward - f(x)) / h
    return grad
```

## 误差分析

总误差 = 截断误差 + 舍入误差

- **截断误差**：随$h \rightarrow 0$而减小 
- **舍入误差**：当$h$过小时，$f(x+h)−f(x)$的精度损失增大

最优步长经验公式：  
$$h_{opt} \approx \sqrt \epsilon⋅max⁡(|x|,1)$$
其中$\epsilon$为机器精度（float32约$10^{−7}$, float64约$10^{−15}$）

## 优缺点比较

| **优点**     | **缺点**         |
| ---------- | -------------- |
| 实现简单       | 计算成本高（需多次调用函数） |
| 不依赖解析表达式   | 高维参数时效率低下      |
| 适用于任意可调用函数 | 存在精度限制         |

## 应用注意事项

- **步长选择**
	- 通常取$h\in [10^{−7},10^{−5}]$
- **函数平滑性**
	- 需要保证函数在$x$附近足够平滑。
- **计算效率**
	- 参数维度$n$需要$n+1$次函数调用。
- **数值稳定性**
	- 避免除零和溢出问题。

## 总结

数值微分是：
- 梯度验证的基础工具（与解析梯度对比）
- 简单场景下的备用方案
- 理解自动微分（Autograd）的基石

在深度学习框架中，通常优先使用自动微分，但数值微分仍可用于：
- 梯度检查（Gradient Checking）
- 快速原型验证
- 黑盒函数的优化
