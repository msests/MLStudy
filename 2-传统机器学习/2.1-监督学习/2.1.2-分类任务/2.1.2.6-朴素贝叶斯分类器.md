## 原理

朴素贝叶斯（Naive Bayes）是基于**贝叶斯定理**和**特征条件独立假设**的分类算法。其核心公式为：
$$P(y|x_1, x_2, ..., x_n) = \frac{P(y)P(x_1, x_2, ..., x_n|y)}{P(x_1, x_2, ..., x_n)}$$

- ​**条件独立假设**：假设所有特征$x_i$在给定类别$y$时彼此独立，即：
$$P(x_1, x_2, ..., x_n|y) = \prod_{i=1}^n P(x_i|y)$$
- 最终简化为：
$$P(y|x_1, ..., x_n) \propto P(y)\prod_{i=1}^n P(x_i|y)$$
  $\propto$意思是正相关于，因为$P(x_1, x_2, ..., x_n)$是固定的数值，我们只需要考虑$P(y)$和$\prod_{i=1}^n P(x_i|y)$。

## 训练过程

1. ​**计算先验概率**：统计训练集中每个类别$y$的频率：
$$P(y) = \frac{\text{类别为$y$的样本数}}{\text{总样本数}}$$
2. ​**计算条件概率**：
   - 对离散特征，统计特征$x_i$在类别$y$下的频率：
$$P(x_i|y) = \frac{\text{类别为$y$且$x_i$取特定值的样本数}}{\text{类别为$y$的样本数}}$$
   - 对连续特征，假设服从高斯分布，计算均值和方差：
$$P(x_i|y) = \frac{1}{\sqrt{2\pi\sigma_y^2}}e^{-\frac{(x_i-\mu_y)^2}{2\sigma_y^2}}$$
3. ​**拉普拉斯平滑**：避免零概率问题，对离散特征调整公式为：
$$P(x_i|y) = \frac{\text{计数} + \alpha}{\text{总样本数} + \alpha N}$$
   其中$\alpha$为平滑系数，$N$为特征$x_i$的可能取值数。

## 优点和缺点

### 优点

- ​**简单高效**
	- 训练和预测速度快，时间复杂度低。
- ​**高维数据友好**
	- 特征独立假设减少计算复杂度。
- **小样本表现好**
	- 对训练数据量要求不高。
- **鲁棒性**
	- 对缺失数据和噪声不敏感。

### 缺点

- ​**独立性假设不成立**
	- 实际场景中特征往往存在相关性，导致模型偏差。
	- 因此叫做朴素贝叶斯，理想情况下的做法。
- **零概率问题**
	- 未出现的特征组合需平滑处理。
- **先验分布影响大**
	- 假设了$P(x_i|y)$的分布，若实际数据分布与假设不符，效果下降。
- ​**概率估计不准确**：
	- 输出的概率值仅用于排序，未必反映真实概率。
